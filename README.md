
# 🌙 Umbra — Lightweight SoundCloud Desktop Client

**Umbra** is a fast, lightweight, and responsive SoundCloud desktop client written in Python and Qt. Designed for seamless background playback with minimal resource consumption.

---

## ✨ Features

- 🎧 **Native Playback:** Powered by VLC engine for stable and clean audio stream.
- 💬 **Discord Rich Presence:** Shows your current playing track, artist, and playback progress directly in Discord.
- ⚡ **Low Resource Usage:** Uses significantly less RAM and CPU compared to running SoundCloud in a web browser.
- 🌐 **Built-in Web Engine:** Smoothly handles SoundCloud API authorization and challenges.
- 🎨 **Minimalist UI:** Clean dark-themed user interface focused purely on music.

---

## 📥 Download & Installation

1. Go to the [**Releases**](https://github.com/weddingcake-1/UmbraClient/releases) page.
2. Download the latest `Umbra.exe` file.
3. Make sure you have [**VLC Media Player (64-bit)**](https://www.videolan.org/vlc/) installed on your PC.
4. Run `Umbra.exe` and enjoy your music!
